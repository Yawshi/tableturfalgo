Final year capstone project, where I developed a modular AI play agent system for Tableturf Battle, a virtual board game in Splatoon 3!

- sole ownership, 6 months for research, implementation and report write-up
- achieved a grade of 78%
- agents are different versions of Minimax and Monte Carlo Tree Search algorithms
- agents can be made to play for either side, and against each other
- writes game results and operation statistics to log files
